This is a guide that explains how the epimight pipeline works, how you prepare your
data and how you run the pipeline on said data.

- Any data shown in this guide comes from [[../data/pipeline-tte.csv][this randomly generated time-to-event dataset]]
- All code shown in this guide have been written to [[./guide.R][this R file]]

* How it works

The pipeline estimates genetic correlation between 2 binary traits using time-to-event data
of individuals and their relatives in a target cohort.

Let's say we want to estimate genetic correlation between earliest diagnosis of schizophrenia
and coronary artery disease in full siblings. Schizophrenia will be trait 1 (~t1~) and
coronary artery disease will be trait 2 (~t2~).

For each trait the pipeline needs the following information of each individual in the target cohort:

- Trait status (0 = censored, 1 = diagnosed, 2 = competing risk)
- Trait time (individual's age at status)
- Amount of full siblings
- Amount of full siblings with trait

Once the pipeline has all needed information, it can begin producing the genetic correlation.
You can think of this process as a series of steps that take inputs and produce outputs.

The first step is producing 2 additional cohorts from the target cohort, so that there are
3 cohorts in total:

| Abbreviation | Description                                                |
|--------------+------------------------------------------------------------|
| ~pop~        | Population or "target cohort"                              |
| ~fh1~        | Individuals with at least 1 full sibling that have trait 1 |
| ~fh2~        | Individuals with at least 1 full sibling that have trait 2 |

The next step is to estimate cumulative incidences for the 2 traits and 3 cohorts.
This step produces 5 different cumulative incidence trait and cohort combinations:

| Abbreviation | Description                                 |
|--------------+---------------------------------------------|
| ~cif_t1_pop~ | CIF of trait 1 from population cohort       |
| ~cif_t1_fh1~ | CIF of trait 1 from family history 1 cohort |
| ~cif_t1_fh2~ | CIF of trait 1 from family history 2 cohort |
| ~cif_t2_pop~ | CIF of trait 2 from population cohort       |
| ~cif_t2_fh2~ | CIF of trait 2 from family history 2 cohort |

The next step is to estimate heritability for the 2 traits. This is done
by comparing the cumulative incidences of a trait in the target cohort and the
family history cohort of the trait:

| Abbreviation | Description             | Created from                  |
|--------------+-------------------------+-------------------------------|
| ~h2_t1~      | Heritability of trait 1 | ~cif_t1_pop~ and ~cif_t1_fh1~ |
| ~h2_t2~      | Heritability of trait 2 | ~cif_t2_pop~ and ~cif_t2_fh2~ |

The final step is to estimate the genetic correlation between the 2 traits,
which is done by using:

- CIF of trait 1 of the target cohort
- CIF of trait 2 of the target cohort
- CIF of trait 1 of the family history 2 cohort (cross trait)
- H2 of trait 1
- H2 of trait 2

* Setting up the pipeline

To setup the pipeline, we start by importing the epimight library:

#+BEGIN_SRC R :exports code :eval no
library(dplyr)
library(readr)
library(data.table)
library(epimight)
#+END_SRC

#+BEGIN_SRC R :exports none :eval no
tte <- read_csv(
  "./test-tte.csv",
  show_col_type = FALSE,
  col_types = cols(person_id = col_character()),
) |> as.data.table()
#+END_SRC

And then create a new instance with our TTE pool (the variable ~tte~ is the data table shown in the previous chapter):

#+BEGIN_SRC R :exports both
pipeline <- Pipeline$new(pool = tte)
#+END_SRC

#+RESULTS:

The supplied pool must be a ~data.table~ with the following required columns:

- ~person_id~
  - Must be a string
  - (Using integers can break joining operations if the values are very large)
- ~trait~
  - Must be a string
- ~trait_status~
  - Must be one of these integers:
    - ~0~ (censored)
    - ~1~ (had trait)
    - ~2~ (competing risk)
- ~trait_time~
  - Must be numeric, minimum ~0.0~
- ~relatives_kind~
  - Must be a string
- ~relatives_n~
  - Must be an integer, minimum ~0~
- ~relatives_n_trait~
  - Must be an integer, minimum ~0~

It accepts any additional columns used for stratification.

* Running the pipeline

After creating the pipeline instance, we run the pipeline by supplying the ~run~ function with:

#+BEGIN_SRC R :exports code :results output
results <- pipeline$run(
  analysis1 = list(
    trait          = "SCZ",
    relatives_kind = "parents",
    relatedness    = 0.5
  ),
  analysis2 = list(
    trait          = "CAD",
    relatives_kind = "full_siblings",
    relatedness    = 0.5
  ),
  stratify_columns = list("birth_year")
)
#+END_SRC

#+RESULTS:

This will give us the genetic correlation between the two traits and all the intermediate results (cif and h2)
in a named list with the members ~cif~, ~h2~ and ~rg~ that contain the results as ~data.tables~.
