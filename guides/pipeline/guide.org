This is a guide that explains how the epimight pipeline works, how you prepare your
data and how you run the pipeline on said data.

- Any data shown in this guide comes from [[../data/pipeline-tte.csv][this randomly generated time-to-event dataset]]
- All code shown in this guide have been written to [[./guide.R][this R file]]

* How it works

The pipeline estimates genetic correlation between 2 binary traits using time-to-event data
of individuals and their relatives in a target cohort.

Let's say we want to estimate genetic correlation between earliest diagnosis of schizophrenia
and coronary artery disease in full siblings.

For each trait we then need the following information of each individual in the target cohort:

- Trait status (0 = censored, 1 = diagnosed, 2 = competing risk)
- Trait onset (age of individual at status)
- Amount of full siblings
- Amount of diagnosed full siblings

| Term | Description |
|------+-------------|
| ~t1~ | Trait 1     |
| ~t2~ | Trait 2     |

Let's say that our traits should be defined as "earliest diagnosis" and the ~t1~ is for schizophrenia
and ~t2~ is for coronary artery disease.


| Term  | Description                                                           |
|-------+-----------------------------------------------------------------------|
| ~pop~ | Population or "target cohort"                                         |
| ~fh1~ | Individuals from ~pop~, with at least 1 relative that have trait ~t1~ |
| ~fh2~ | Individuals from ~pop~, with at least 1 relative that have trait ~t2~ |

Note: ~fh~ is short for "family history".

That is used in 3 different analyzes:

| Term  | Description                                                                            |
|-------+----------------------------------------------------------------------------------------|
| ~cif~ | Cumulative incidence function                                                          |
| ~h2~  | Heritability                                                                           |
| ~rg~  | Genetic correlation                                                                    |

You can think of the pipeline as a set of data transformations, where each
transformation has inputs and a single output. Some examples of data transformations:

- Filtering out individuals from population TTE data
- Producing population CIF from population TTE data
- Producing H2 from population CIF and family history CIF

The diagram below represents the data transformations that the pipeline consists of,
where the start node is the population TTE data and the end node is the genetic correlation.

The color represents from which trait the individual status/onset was used in the analysis.
The middle CIF (cross trait) is a bit special, since it uses trait 1 status/onset of individuals
that have at least one relative with trait 2.

* Setting up the pipeline

To setup the pipeline, we start by importing the epimight library:

#+BEGIN_SRC R :exports code :eval no
library(dplyr)
library(readr)
library(data.table)
library(epimight)
#+END_SRC

#+BEGIN_SRC R :exports none :eval no
tte <- read_csv(
  "./test-tte.csv",
  show_col_type = FALSE,
  col_types = cols(person_id = col_character()),
) |> as.data.table()
#+END_SRC

And then create a new instance with our TTE pool (the variable ~tte~ is the data table shown in the previous chapter):

#+BEGIN_SRC R :exports both
pipeline <- Pipeline$new(pool = tte)
#+END_SRC

#+RESULTS:

The supplied pool must be a ~data.table~ with the following required columns:

- ~person_id~
  - Must be a string
- ~trait~
  - Must be a string
- ~failure_status~
  - Must be one of these integers:
    - ~0~ (censored)
    - ~1~ (event of interest)
    - ~2~ (competing risk)
- ~failure_time~
  - Must be numeric, minimum ~0.0~
- ~relatives_kind~
  - Must be a string
- ~relatives~
  - Must be an integer, minimum ~0~
- ~relatives_n_trait~
  - Must be an integer, minimum ~0~

It accepts any additional columns used for stratification.

* Running the pipeline

After creating the pipeline instance, we run the pipeline by supplying the ~run~ function with:

- Trait 1
  - Identifier
  - Earliest onset
  - Latest onset
  - What kind of relatives to use for ~fh1~ cohort
  - What coefficient of relationship to use for heritability
- Trait 2
  - Identifier
  - Earliest onset
  - Latest onset
  - What kind of relatives to use for ~fh2~ cohort
  - What coefficient of relationship to use for heritability and genetic correlation
- What stratification columns to use (if any)

For example, if we want to run an analysis between schizophrenia and coronary artery disease of full siblings,
stratifying on birth year, we would run:

#+BEGIN_SRC R :exports code :results output
results <- pipeline$run(
  trait1 = list(
    trait_name     = "SCZ",
    relatives_kind = "parents",
    relatedness    = 0.5
  ),
  trait2 = list(
    trait_name     = "CAD",
    relatives_kind = "full_siblings",
    relatedness    = 0.5
  ),
  stratify_columns = list("birth_year")
)
#+END_SRC

#+RESULTS:

This will give us the genetic correlation between the two traits and all the intermediate results (cif and h2)
in a named list with the members ~cif~, ~h2~ and ~rg~ that contain the results as ~data.tables~.
